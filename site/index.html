What it does

A permit lets one Agent ID holder (the principal) cap how much another Agent ID holder (the spender) may send it, for a bounded window. The contract never holds anyone's funds: the only value movement possible is BNB sent by the spender to the principal, bounded by the permit cap and expiry.

Every state-changing call checks the SPACE ID Agent ID registry on-chain. The registry lives at 0x60b9262456de011f7d15a54cdd8c48baaa8b022f (ERC-721, soulbound, one per user). This contract only reads balanceOf and handleOf from it, and never resolves a handle back to an address.

Permission disclosure

No owner. No admin. No fee. No pause. No upgrade. No blacklist. No tax. No arbitrary transfer function. The registry address and the badge supply cap are immutable. A permit can only move BNB from its own spender to its own principal, and only while it is active and under cap. The principal can revoke at any time. There is no path by which a third party's funds move.

Badge

One ERC-721 badge per Agent ID holder, free, gas only. The metadata is fully on-chain: the holder's .ai handle is rendered as an SVG inside a standard ERC-721 JSON metadata document. No IPFS, no external image host.

How to use it

Claim your own Agent ID first — it can only be done inside the Binance App:

Wallet → homepage banner → Agent ID

Then, from a wallet that holds one:

// 1. mint the free badge
mintBadge()

// 2. principal allows a spender, capped and time-bounded
createPermit(spender, cap, duration)   // duration: 1 hour – 30 days

// 3. the spender sends value under the permit
spend(permitId)                        // payable

// 4. the principal can pull it back at any time
revoke(permitId)

Read the chain

holdsAgentId(address)   -> bool
handleOf(address)         -> string        // .ai handle, display only
remaining(permitId)       -> uint256       // wei still spendable
isActive(permitId)        -> bool
permitInfo(permitId)      -> (principal, spender, handle, cap, spent, expiry, revoked)
permitsOf(principal)      -> uint256[]
badgeOf(address)          -> uint256

Try it on your own chain

Any wallet with an Agent ID can call the contract directly. The badge mint costs only gas.
